# 💻 C Programs

Welcome to my **C Programs** repository! 👋

This repository contains C language programs that I create while learning and practicing programming. It is a collection of practice problems and basic programs to improve my coding skills.

## 📂 Repository Contents

- `hello.c` — C language practice program.

## 🛠️ Technologies Used

- **Language:** C
- **Compiler:** GCC
- **Editor:** VS Code (or any C editor)

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/iszAkshay2006/C-Programs.git
   ```

2. Open the repository folder:

   ```bash
   cd C-Programs
   ```

3. Compile the program using GCC:

   ```bash
   gcc hello.c -o hello
   ```

4. Run the program:

   **Windows:**
   ```bash
   hello.exe
   ```

   **Linux/macOS:**
   ```bash
   ./hello
   ```
